# `@deepseek-ai/dsh-gstar-data-source-reference`

[English](README.md) | 中文

一个权威 GSTAR 参考来源的声明式插件。每条 Cordis 行提供稳定 id、公开名称、发布机构、HTTP(S) 入口、覆盖的 AOI 类型和默认局点启用状态。插件注册核验能力，并明确不贡献同步操作。

GSTAR Profile 分别用本包实例化国家公共数据资源登记平台、国家政务服务平台、国家企业信用信息公示系统、国家金融监督管理总局许可证查询、教育部高校名单和国家卫生健康委员会数据查询。虽然实现包共享，但每个实例都有独立动态生命周期和局点开关。

## 模型体验

无，因为参考元数据只进入 Host 与浏览器产品投影。

#### KV Cache 影响

无。

## 已知限制与暂缓事项

- 启用参考来源只表示核验策略可以使用它，不会抓取或导入该平台。
- 身份认证、反爬流程和来源专用字段匹配需要独立数据源插件，不能用通用配置替代。
- 配置 URL 只校验 HTTP(S) 语法；发布机构权威性与内容时效仍由部署评审负责。
