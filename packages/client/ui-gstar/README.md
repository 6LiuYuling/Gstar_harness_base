# @deepseek-ai/dsh-client-ui-gstar

English | [中文](README.zh.md)

GSTAR browser root shell. It occupies the built-in `root` slot and projects durable DSH Workspaces as station workspaces. The first delivery deliberately shows unavailable region, source, gate, and pipeline metrics as pending instead of manufacturing product data in React.

## Model Experience

None. The package is presentation-only and contributes no model-visible input.

#### KV Cache effect

None.

## Known Limitations and Deferred Work

- Region assets and plugin/pipeline projections are not yet wired; their navigation seats identify the next Host services without presenting mock records.
- Workspace creation remains disabled until the station domain can create and validate the accompanying station profile atomically.
